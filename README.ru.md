# OpenHasp - интеграция сенсорных панелей

![OpenHasp Icon](static/OpenHasp.png)

Плагин `OpenHasp` подключает панели на базе `openHASP` к `osysHome` через MQTT. Модуль автоматически обнаруживает панели, хранит их конфигурацию в базе и умеет синхронизировать экранные элементы со свойствами объектов системы.

## Что умеет плагин

- автоматически регистрировать панели по MQTT `discovery`;
- отправлять страницы и объекты на панель командами `jsonl` и `json`;
- переключать страницы через API и административный интерфейс;
- связывать поля панели со свойствами `osysHome` через шаблоны вида `%Object.property%`;
- вызывать методы объектов по событиям нажатия;
- подставлять значения в шаблоны и переиспользуемые блоки `templates`;
- обновлять элементы панели при изменении связанных свойств.

## Быстрый старт

1. Настройте MQTT-брокер в разделе `OpenHasp -> Settings`.
2. Укажите список топиков для подписки, например `hasp/discovery/#,hasp/+/state/#,hasp/+/LWT,hasp/+/statusupdate,hasp/+/idle`.
3. Включите `openHASP` на панели и убедитесь, что она публикует `discovery`.
4. Дождитесь автоматического появления панели в списке устройств.
5. Откройте панель на редактирование и вставьте JSON-конфигурацию в поле `Config`.
6. Нажмите кнопку перезагрузки страниц в списке устройств.

## MQTT и API

Плагин работает с корневым путём панели `mqtt_path`, например `hasp/kitchen`.

Используемые команды:

- `hasp/<panel>/command` - строковые команды `jsonl`, `clearpage`, `p0b1.delete`;
- `hasp/<panel>/command/<key>` - установка отдельных значений, например `page`, `backlight`, `idle`;
- `GET /api/OpenHasp/page/<device_id>/<page>` - открыть страницу панели;
- `GET /api/OpenHasp/panels` - вернуть список зарегистрированных панелей и их конфиг.

> [!NOTE]
> Поля вида `up_command`, `down_command` и аналогичные в текущем коде используются как внутренние управляющие инструкции плагина и обрабатывают только специальные значения `delete` и `close`. Для произвольных MQTT-команд панели они сейчас не подходят.

## Административный интерфейс

В модуле доступны:

- список найденных панелей;
- переход в Web UI устройства по IP;
- просмотр скриншота панели;
- ручная перезагрузка страниц;
- редактирование `mqtt_path` и JSON-конфига панели.

## Требования

- MQTT-брокер;
- панель с прошивкой `openHASP`;
- установленный пакет `paho-mqtt`;
- рабочая объектная модель `osysHome`, если используются привязки `%Object.property%`.

## Структура конфигурации панели

Конфиг панели хранится в поле `Config (JSON)` и обычно содержит:

```json
{
  "page_linkedProperty": "%PanelKitchen.page%",
  "idle_linkedProperty": "%PanelKitchen.idle%",
  "value_event": "up",
  "pages": [
    {
      "comment": "Главная",
      "objects": []
    }
  ],
  "templates": {}
}
```

Подробное описание всех поддерживаемых полей и готовые шаблоны есть в документе [Настройка панелей и примеры конфигурации](docs/PANEL_CONFIGURATION.ru.md).
